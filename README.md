# Python 'Love' Module
A Python module to calculate the score between two names, based on the character count.

# How to Use
Just download `luvmod.py` of this repo to a local folder or repository, create a `main.py` (or whatever filename) with `import luvmod`, and write/use something like the `example_main.py` of this repo. (replace the names 'Kira' and 'Yuki' to your liking).
