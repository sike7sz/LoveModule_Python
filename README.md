# Python 'Love' Module
A Python module to calculate the score between two names, based on the character count.

# How to Use
Just download `luvmod.py` (or with `pip install luvmod`) of this repo to a local folder or repository, create a `main.py` (or whatever filename) with `import luvmod`, and write/use something like the `example_main.py` of this repo. (replace the names 'Kira' and 'Yuki' to your liking).

example_main.py:
```python
# main.py
import luvmod

# Calls the say_it function from love.py
print(love.say_it())

# Calls the compatibility function from love.py with two names
result = love.compatibility("Kira", "Yuki")
print(result)
```
